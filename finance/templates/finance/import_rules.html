Jak działają reguły i jak zapisać słowa

Najprościej: w podglądzie importu popraw kategorię i zaznacz „Zapamiętaj”. Aplikacja szuka słów w nazwie {% if is_expense %}sklepu{% else %}nadawcy{% endif %}, opisie i kontrahencie z wyciągu. Podpowiedź pochodzi z pierwszego pasującego miejsca:

  1. Twoje reguły, od góry – wygrywa pierwsza pasująca.
    2. {% if is_expense %}
  2. Przelew do biura maklerskiego → Inwestycje (reguła wbudowana).
    3. {% endif %}
  3. Historia – jak ostatnio zapisano pozycję {% if is_expense %}z tego sklepu{% else %}o tym opisie{% endif %}.
  4. Reguły wbudowane – lista na dole strony.

Zasady zapisu

  • Przecinek Oddziela słowa: fred, malinogród. Można też pisać w osobnych liniach.
  • Całe słowo ola trafi w „OLA SKLEP”, ale nie w „KOLACJA”.
  • Gwiazdka Na końcu oznacza początek słowa: pierog* trafi w „Pierogi”, „Pierogarnia”.
  • Fraza Kilka słów musi wystąpić w całości i w tej kolejności: mr cleaner.
  • Litery Wielkość liter i polskie znaki nie mają znaczenia – bank często je gubi: żabka = ZABKA.
